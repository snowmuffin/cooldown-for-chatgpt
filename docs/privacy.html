Privacy Policy

Cooldown for ChatGPT · Last updated: October 19, 2026 (auto reload added)

Cooldown for ChatGPT does not collect, transmit, sell, or share any data. It has no server, no analytics, and no remote code. Everything it observes stays in your browser.

What the extension reads

On https://chatgpt.com only, the extension observes the outcome of the page's own network requests:

  • the request method and URL (path and query, which can include a conversation ID),
  • the HTTP status code and, for HTTP 429 responses, the Retry-After header,
  • network error codes (for example net::ERR_ABORTED) and timestamps.

It never reads request or response bodies, so it never sees your messages, ChatGPT's replies, your account details, cookies, or passwords. It does not block or modify any request.

Where it is kept

Observations are kept in chrome.storage.session, which lives in memory on your device. It is cleared when you close a tab (for that tab), when the browser restarts, or when the extension is updated or disabled. The history list in the popup keeps at most 50 entries, and you can clear it at any time. The only things written to disk are your two settings (auto reload on/off and the interface language), in chrome.storage.local. Nothing leaves your device.

Auto reload

Auto reload is off by default. When you turn it on, the extension reloads a chatgpt.com tab only when that tab shows ChatGPT's "can't load this chat" error caused by a 429, and only after the server's Retry-After time has passed. It reloads that tab and no other, at most 3 times in 10 minutes per tab, and waits while the message box holds unsent text.

Permissions

  • webRequest — read response status and headers of chatgpt.com requests. Nothing is blocked or changed.
  • storage — keep the in-memory state described above.
  • alarms — remove expired entries on time.
  • Host access to https://chatgpt.com/* — the only site the extension runs on.

Changes and contact

Changes to this policy are published on this page and in the source repository. Questions can be filed as an issue.

Independent project. Not affiliated with or endorsed by OpenAI.

개인정보처리방침

Cooldown for ChatGPT · 최종 수정일: 2026년 10월 19일 (자동 새로고침 추가)

Cooldown for ChatGPT는 어떤 데이터도 수집, 전송, 판매, 공유하지 않습니다. 서버, 분석 도구, 원격 코드가 없으며 관측한 내용은 모두 브라우저 안에만 머뭅니다.

확장 프로그램이 읽는 정보

https://chatgpt.com에서만, 페이지가 스스로 보내는 네트워크 요청의 결과를 관측합니다.

  • 요청 메서드와 URL(경로와 쿼리, 대화 ID가 포함될 수 있음)
  • HTTP 상태 코드, 그리고 429 응답의 Retry-After 헤더
  • 네트워크 오류 코드(예: net::ERR_ABORTED)와 시각

요청과 응답의 본문은 읽지 않습니다. 따라서 메시지 내용, ChatGPT의 답변, 계정 정보, 쿠키, 비밀번호를 볼 수 없습니다. 어떤 요청도 차단하거나 변경하지 않습니다.

보관 위치

관측 내용은 기기 메모리에 있는 chrome.storage.session에 보관됩니다. 탭을 닫으면 해당 탭의 기록이, 브라우저를 다시 시작하거나 확장 프로그램을 업데이트·비활성화하면 전체가 지워집니다. 팝업의 기록 목록은 최대 50개이며 언제든 지울 수 있습니다. 디스크에 저장하는 것은 설정 두 가지(자동 새로고침 켜기/끄기, 표시 언어, chrome.storage.local)뿐이며, 기기 밖으로는 아무것도 보내지 않습니다.

자동 새로고침

자동 새로고침은 기본으로 꺼져 있습니다. 켜면, chatgpt.com 탭이 429 때문에 "대화를 불러올 수 없습니다" 오류를 띄웠을 때만, 그리고 서버가 알려준 Retry-After 시간이 지난 뒤에만 그 탭을 새로고침합니다. 다른 탭은 건드리지 않으며, 탭마다 10분에 최대 3번까지이고, 입력창에 보내지 않은 글이 있으면 기다립니다.

권한

  • webRequest — chatgpt.com 요청의 응답 상태와 헤더를 읽습니다. 차단하거나 변경하지 않습니다.
  • storage — 위에서 설명한 메모리 내 상태를 보관합니다.
  • alarms — 만료된 기록을 제때 지웁니다.
  • https://chatgpt.com/* 접근 — 확장 프로그램이 동작하는 유일한 사이트입니다.
