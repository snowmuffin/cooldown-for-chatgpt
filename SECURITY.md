# Security policy

## Supported code

Security fixes are made on `main` and included in the next release. Older versions
do not have a separate maintenance branch; update to the latest available version.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/snowmuffin/cooldown-for-chatgpt/security/advisories/new).
Do not open a public issue for an unpatched vulnerability.

Include the affected extension version or commit, a description of the impact, and
minimal reproduction steps using synthetic data. Do not send passwords, tokens,
cookies, private conversation content, or unredacted network captures.

This policy covers the extension and its repository workflows. Problems in ChatGPT
itself should be reported to OpenAI through its official reporting channels.
Ordinary rate limiting or conversation loading failures belong in the bug report
form unless they demonstrate a security vulnerability in this extension.

This is a volunteer-maintained project; there is no guaranteed response time or
bug bounty. Coordinate disclosure with the maintainer in the private report.
